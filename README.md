## 天地劫：幽城再临
### 手游《天地劫：幽城再临》PC 端战斗统计工具

**访问 [https://itx351.github.io/tdj_act/](https://itx351.github.io/tdj_act/) 在线使用。**

---

### 使用方法

1. **战斗结束后关闭游戏客户端。**
2. **找到手游的数据存储路径：**
   - 路径示例：`C:\Users\your_username\AppData\LocalLow\紫龙游戏\天地劫：幽城再临\Config`
3. **找到本次战斗生成的全部 `.bl` 分片：**
   - 文件示例：`9834750923847561982_11223344(9876543210)_20250227_123456.bl`
   - 括号内的 `9876543210` 是战斗 ID。
4. **找到所有括号内战斗 ID 相同的文件，并在文件选择窗口中一次性全部选中。**
5. **工具会按战斗 ID 自动分组并按时间排序；选择目标战斗后点击“分析”。**

---

### 其他事项

- 所选战斗文件的总大小不能超过 100MB。
- 工具直接读取游戏输出的 `userId2BattleStatistics` 汇总结果，不再通过逐条日志和血量差反推伤害。
- 输出只有一张单位统计表，包含总伤害、首领伤害及占比、承伤、治疗、暴击次数和最高单次伤害。
- JSON 中没有可读单位名，因此仍会从同批日志的 `charId/charName` 信息补齐；找不到名称时显示 CharId。
- 文件只在浏览器本地读取，不会上传到服务器。
- JSON 字段说明见 [`docs/JSON_SAMPLE_GUIDE.md`](docs/JSON_SAMPLE_GUIDE.md)。

### 服务器 React.js 配置

#### Setup

运行以下命令以安装所有依赖项：
```sh
npm install
```

#### Running

运行以下命令并访问 `localhost:3000` 进行调试：
```sh
npm start
```

#### Release

运行以下命令以生成最小化的生产版本：
```sh
npm run build
```
